# playroom

**English** · [한국어](#korean)

A hobby playroom. One folder per experiment, each with its own short README.

## Contents

- [usage-hud](usage-hud/) — Claude Code subscription limits as a retro game HUD: hearts for the weekly limit, a bolt for the five-hour one, a coin for what today would have cost at API prices. A click-through overlay that stays on top of everything, plus a browser page with the last seven days. On macOS it sits in the menu bar instead
- [weather](weather/) — snow, rain, a thunderstorm, hail, fireflies or fireworks over every window, picture-in-picture video included. Clicks go straight through to whatever you are working on; snow piles up on the taskbar and slowly melts. An optional pixel cat or bird wanders along the taskbar, with or without weather. Also runs on macOS, with its icon in the menu bar
- [sysmon](sysmon/) — CPU and memory use in two small lines on the taskbar, just left of the notification icons. Turns orange above 70% and red above 90%. A pixel theme matches usage-hud, which can sit on the taskbar right next to it. Also runs on macOS, in the menu bar
- [layers](layers/) — decides which always-on-top window goes in front: the overlays here, a picture-in-picture video, any window you add. Without it the overlays take turns jumping in front of each other
- [shared](shared/) — the tray icon, per-pixel alpha window, taskbar text, single-instance, work-area and start-with-Windows helpers the overlays share

## Korean

취미용 놀이방. 실험 하나당 폴더 하나로 두고, 폴더마다 짧은 README 를 붙임.

### 구성

- [usage-hud](usage-hud/) — Claude Code 구독 한도를 레트로 게임 HUD 로 보여 줌. 하트는 7일 한도, 번개는 5시간 한도, 동전은 오늘 쓴 양을 API 정가로 친 값. 모든 창 위에 떠 있되 클릭은 통과시키는 오버레이와, 7일치를 함께 보는 브라우저 페이지. 맥에서는 메뉴 막대에 뜸
- [weather](weather/) — PIP 영상까지 포함해 모든 창 위로 눈·비·뇌우·우박을 내리거나 반딧불이·불꽃놀이를 띄움. 클릭은 하던 작업으로 그대로 통과하고, 눈은 작업 표시줄 위에 쌓였다가 천천히 녹음. 픽셀 고양이나 새를 켜면 날씨와 같이 또는 혼자 작업 표시줄 위를 돌아다님. 맥에서도 돌고, 아이콘은 메뉴 막대에 뜸
- [sysmon](sysmon/) — 작업 표시줄의 알림 아이콘 바로 왼쪽에 CPU·메모리 사용률을 작은 두 줄로 띄움. 70% 를 넘으면 주황, 90% 를 넘으면 빨강. 픽셀 테마는 usage-hud 와 같은 모양이고, usage-hud 를 작업 표시줄에 두면 바로 옆에 붙음. 맥에서도 돌고, 메뉴 막대에 뜸
- [layers](layers/) — 맨 위에 뜨는 창들 중 무엇이 앞에 올지 정함. 여기 오버레이들, PIP 영상, 직접 넣은 아무 창이나. 없으면 오버레이들이 서로 번갈아 앞으로 튀어나옴
- [shared](shared/) — 오버레이들이 같이 쓰는 트레이 아이콘, 픽셀 알파 창, 작업 표시줄 글자, 한 번만 뜨게 하기, 작업 영역, 윈도우 시작 시 실행 코드
